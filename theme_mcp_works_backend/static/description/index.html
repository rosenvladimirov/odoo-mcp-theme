MCP Works — Backend Theme

A hi-tech, minimalist «robot» skin for the Odoo 19 Community backend

Electric-sapphire accents, sharp corners, a fine blueprint mesh, seamless light / dark mode and a vertical Dash dock — applied uniformly across the whole backend. No Enterprise dependency.

Why you will like it

Community-first

Pure CE. Depends only on web and base_setup; explicitly excludes web_enterprise.

Sharp robot identity

Electric-sapphire accent, zero-radius corners, a subtle blueprint grid and monospace telemetry labels.

Light & Dark

A calibrated dark theme ships with the light one — token-driven, accent legible on both grounds.

Vertical Dash dock

A slim, always-there app launcher — expand for names, collapse for icons. Plus a selectable UI font.

Themed everywhere

Every core surface is calibrated — not just the navbar.

  • List & Form views
  • Kanban — flat cards, left-line hover, colour-safe
  • Calendar — sapphire today-marker, light event chips
  • Pivot & Graph
  • Activity view
  • Discuss — rail, composer, RTC call panel, notifications
  • Settings — sapphire nav, sharp panels
  • Search panel, facets, dropdowns & controls

Requirements
