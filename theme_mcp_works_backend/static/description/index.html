MCP Works — Backend Theme

A hi-tech, minimalist “robot” skin for the Odoo 19 Community backend

Electric-sapphire accents, sharp corners, a fine blueprint mesh, seamless light / dark mode and a vertical Dash dock — applied uniformly across the whole backend. No Enterprise dependency. Just install and enjoy a crisp, distinctive workspace.

Why you’ll like it

⚡ Independent & Community-first

Pure CE. Depends only on web and base_setup, and explicitly excludes web_enterprise. No paid tiers required.

◆ Sharp “robot” identity

Electric-sapphire accent, zero-radius corners, a subtle blueprint grid and monospace “telemetry” labels give the backend a clean, engineered feel.

☾ Light & Dark mode

A carefully calibrated dark theme ships alongside the light one — token-driven, with the accent kept legible on both grounds.

Themed everywhere

Every core surface is calibrated — not just the navbar:

  • List & Form views
  • Kanban (flat cards, left-line hover, colour-safe)
  • Calendar (sapphire today-marker, light event chips)
  • Pivot & Graph
  • Activity view
  • Discuss (rail, composer, RTC call panel, notifications)
  • Settings (sapphire nav, sharp panels)
  • Search panel, facets, dropdowns & controls

🎛️ Vertical “Dash” dock

A slim, always-there app launcher on the side — expand for names, collapse for icons.

🔤 Selectable UI font

Pick the interface typeface from Settings; the choice is applied before the client paints, so there’s no flash.

Requirements
